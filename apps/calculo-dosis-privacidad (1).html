POLÍTICA DE PRIVACIDAD

Cálculo de Dosis

Última actualización: 12 de septiembre de 2026

Resumen:

Cálculo de Dosis es una herramienta destinada a efectuar cálculos de diferentes tipos de dosis y unidades. La aplicación no está diseñada para registrar pacientes, historias clínicas ni medicamentos administrados.

1. Responsable

Esta aplicación forma parte de AppVida y Salud, proyecto dedicado al desarrollo de herramientas digitales orientadas a las necesidades de funcionarios, profesionales, estudiantes y primeros respondedores del área de la salud.

2. Información que recopila la aplicación

Cálculo de Dosis no requiere que el usuario cree una cuenta ni proporciona un sistema para registrar datos personales.

La aplicación utiliza los valores introducidos por el usuario para efectuar los cálculos solicitados. Estos valores tienen como finalidad proporcionar el resultado del cálculo y no constituyen un registro clínico.

3. Pacientes y medicamentos

La aplicación no está diseñada para crear ni mantener fichas de pacientes, historias clínicas o registros de atención.

Tampoco mantiene un registro de medicamentos administrados. La utilización de nombres, concentraciones u otros valores dentro de un cálculo, cuando corresponda a las funciones de la aplicación, no significa que se esté creando un historial de administración de medicamentos.

4. Datos personales y sensibles

Cálculo de Dosis no solicita al usuario datos personales para realizar sus cálculos y no está destinada a recopilar información de salud de pacientes.

Se recomienda no introducir nombres, identificadores de pacientes, números de ficha, información clínica u otros datos personales que no sean necesarios para el cálculo.

5. Uso de la información

Los datos ingresados se utilizan para realizar la función de cálculo solicitada por el usuario. La aplicación no utiliza esos datos para crear perfiles de usuarios, vender información ni realizar publicidad personalizada basada en información de salud.

6. Compartición de información

Cálculo de Dosis no proporciona una función destinada a compartir registros de pacientes o historiales de medicamentos con terceros.

No se venden datos personales a terceros.

7. Servicios de terceros

Esta política describe el funcionamiento de privacidad previsto para la aplicación. Si en una futura versión se incorporan servicios externos que impliquen una modificación relevante en el tratamiento de datos, esta política será actualizada antes o junto con dicha modificación, según corresponda.

8. Seguridad

Se aplican medidas razonables de diseño para mantener la aplicación como una herramienta de cálculo y evitar que se convierta en un sistema de registro de información clínica.

9. Menores de edad

La aplicación está orientada principalmente a funcionarios, profesionales, estudiantes y personas que utilizan herramientas de apoyo relacionadas con salud y educación. No está diseñada específicamente para recopilar información de menores.

10. Cambios en esta política

Esta política puede actualizarse cuando se incorporen nuevas funciones o cuando sea necesario aclarar aspectos relacionados con privacidad. La fecha de actualización indicada al comienzo de esta página permite identificar la versión vigente.

11. Contacto

Para consultas relacionadas con esta Política de Privacidad o con Cálculo de Dosis, puedes contactar al responsable del proyecto AppVida y Salud.

Sitio principal: appsvidaysalud.com

12. Aviso sobre el uso de la aplicación

Cálculo de Dosis es una herramienta de apoyo. No sustituye el juicio clínico, la formación profesional, los protocolos institucionales, las guías oficiales ni la verificación independiente de los resultados. El usuario es responsable de comprobar los datos ingresados, las unidades, las fórmulas aplicables y el resultado antes de utilizarlo en un contexto asistencial.
